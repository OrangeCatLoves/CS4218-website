<header class="page-header">
  <h1>Module Overview</h1>
  <p class="page-lead">
    This course covers the concepts and practice of software testing including unit testing, integration testing, and regression testing. Various testing coverage criteria will be discussed. The use of testing and analysis for performance prediction, performance clustering and performance debugging will be studied. Students will acquire crucial skills on testing and test tools through hands-on activities. There will be special focus on testing in the industry. In order to gain practical industrial testing knowledge, there will be a project which uses current testing best practices, tools and techniques from industry.
  </p>
</header>
